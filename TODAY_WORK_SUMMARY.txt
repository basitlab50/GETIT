[19:15:00] Complete Cross-Device Cloud Sync via Supabase JSONB (Commit fc6b624)
  - Root Cause Diagnosed: Orders in Supabase previously only held basic top-level fields (items, total, name),
    while `stops` (pickup sequence checklist), `roadRouteCoordinates` (blue road polyline), and `roadLegs`

    not render the pickup stops timeline, the shop markers, or the blue road routes.

    `currentStopIndex`, and `journeyAlert` inside the native `bolt_rider` JSONB column in Supabase.
  - Resilient Auto-Reconstruction: Updated `getDatabaseOrders` so that if an older order was saved without
    explicit stops, it dynamically reconstructs the multi-store `stops` array from item metadata and store coordinates.
  - Direction Points Cloud Sync: Updated `fetchRealRoadDirections` so that once snapped road coordinates are
    computed, they are immediately persisted to Supabase via `updateDatabaseOrderStatus`.
  - Bidirectional Cloud Sync: Updated `syncOrdersFromCloud` so that when Device 1 syncs, it uploads all local
    orders with their full stops and route geometry to Supabase; Device 2 then downloads them completely.
  - Map Route Rendering: Enhanced the order tracking map to display both the full roadmap path connecting all
    stores to the home destination, as well as the active courier transit leg with fallback geometry.
