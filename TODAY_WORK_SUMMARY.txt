[04:30:00] Fix Store Operating Days Evaluation (Weekends Only / Custom Schedules)
  - Implemented `isStoreOpenOnDay` to evaluate store operating days against current device day.
  - Connected day validation to `isStoreCurrentlyOpen(store)`: stores set to "Weekends Only"

    buyer interface (store cards, explore map, catalog products, booking modal, and checkout).
  - Enhanced `getStoreTimingBadge` to display `🔴 Closed Today • <OperatingDays>` instead of

  - Updated live customer preview card in the timing modal so merchants see immediate real-time
    feedback when switching operating days.
  - Synced database `isOpen` field upon merchant saving operating schedules.

[10:52:00] Animated Storefront Door for Closed Stores
  - Created `AnimatedStoreDoor` component in `mobile/App.js` with realistic double French doors
    that smoothly slide and swing shut with spring physics when a store is closed.
  - Added central golden deadbolt / padlock (`🔒 LOCKED`) that snaps shut with spring bounce when doors meet.
  - Added authentic hanging wooden signboard (`⛔ SORRY, WE'RE CLOSED`) that gently sways with
    continuous pendulum loop animation.
  - Added interactive "🚪 Knock on Door" button with physical vibration shake and playful speech bubbles
    informing buyers of operating schedule while reassuring them that catalog browsing is active.
  - Added "Replay Close 🔄" button to let users replay the door close sequence anytime.

[15:05:00] Fix Closed Door Animation Driver & Prominent Top Placement
  - Fixed `useNativeDriver` setting from `true` to `false` in `AnimatedStoreDoor` so animations run

  - Moved `AnimatedStoreDoor` to the very top of the Store Details page directly replacing/framing the top
    banner image, ensuring users immediately see the animated doors close shut the instant they open a closed store.
  - Added closed storefront door facade overlay on store cards in the main Stores feed with lock and sign.
[16:20:00] Multi-Store Basket, Split Dispatch Checkout & Order Cancellation (Roadmap Item #6)
  - Multi-Store Basket Grouping: Grouped cart provisions by store (`cartGroupedByStore`) with
    dedicated shop cards, store name header, open/closed status badge, subtotal, and "Remove Shop" button.
  - Multi-Store Basket Map: Rendered interactive map plotting pins for all participating stores,
    dashed polyline connectors from every shop to delivery destination, and dynamic "Multi-Store Dispatch" banner.
  - Closed Store Checkout Guard: Alerted buyer if any store in basket is closed today, with one-tap
    "Remove Closed Stores" to proceed with open stores.
  - Split Checkout Tickets: `handleCheckout` automatically generates a multi-store `batchId` (`BATCH-XXXXX`)
    and splits cart into dedicated independent order tickets (`ORD-XXXXX-A`, `ORD-XXXXX-B`).
    Each vendor receives only their store's ticket, 90% payout, and separate pickup/delivery PINs.
  - Order Cancellation & Refund Flow: Allowed buyers to cancel pending/preparing orders directly from
    the Orders tab (`activeTab === 'orders'`) with refund confirmation (`formatNaira(ord.total)`),
    status update to `Cancelled`, reason logging, voided security PIN, and Supabase synchronization.
